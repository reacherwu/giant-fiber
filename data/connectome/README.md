# Connectome subset used by the escape model

Generated by `tools/connectome/extract_escape_circuit.py` from public releases (no login, no API key).
Nothing in this folder is hand-edited; re-run the script to regenerate it, together with
`crates/giantfiber-core/src/connectome/data.rs` and `giantfiber/data/connectome_graphs.py`.

| file | content | source |
|---|---|---|
| `flywire783_escape_edges.csv` | every LPLC2 / LC4 neuron with synapses onto the left or right Giant Fiber (DNp01), with FlyWire root IDs and synapse counts | FlyWire FAFB v783 |
| `flywire783_escape_summary.csv` | per-side totals: LPLC2 / LC4 -> DNp01, and LPLC2 / LC4 -> the non-GF descending neurons below | FlyWire FAFB v783 |
| `flywire783_nongf_dn_types.csv` | the 8 descending-neuron types (other than DNp01) with the most LPLC2 + LC4 input synapses; this "top 8" rule is our modelling choice | FlyWire FAFB v783 |
| `manc121_gf_motor_edges.csv` | DNp01 -> TTMn / PSI and PSI -> DLMn chemical synapse counts in the ventral nerve cord | MANC v1.2.1 |

Notes
- Synapse counts are chemical synapses from automated detection on proofread neurons. The GF -> TTMn
  connection is known to be largely electrical (gap junctions), which no EM connectome counts;
  the MANC numbers here are a lower bound on coupling, not its strength.
- FlyWire left/right refer to the brain hemisphere of the neuron. All LPLC2/LC4 -> GF synapses in
  this table are ipsilateral.
- Weights in the model are synapse counts normalised per target (see `giant_fiber.rs`), not measured
  synaptic strengths.
